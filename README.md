# 반려동물 비대면 진료 서비스 — Backend

반려동물 보호자가 예약 후 수의사와 화상으로 비대면 진료를 받는 서비스의 백엔드입니다. 예약, 화상 진료, 처방전 발급, 결제, 커뮤니티 게시판 기능을 제공합니다.

> 팀 프로젝트로 시작되어(2025.04–06), 프로젝트 중반 팀장이 이탈한 뒤 2025.10–12월 동안 본인이 백엔드를 100% 단독으로 이어받아 완성했습니다. 아래 내용은 본인이 직접 작업한 범위를 설명합니다.

## 담당 역할

- 팀장 이탈 후 3개월간(2025.10–12) 예약·처방전·결제·커뮤니티·인증 등 5개 도메인 백엔드 100% 단독 개발
- 프로젝트 막바지 AWS EC2 배포 단독 진행

## 주요 기능

- **예약(Appointment)**: 날짜·시간 선택, 반려동물 정보, 수의사 선택을 포함한 예약 플로우 API
- **처방전(Prescription)**: 진료 후 처방전 작성·조회 API
- **결제(Payment)**: 진료 결제 처리 API
- **커뮤니티(CommunityPost/Comment)**: 게시글·댓글 API
- **회원(User) 및 인증(Auth)**: 로그인/회원가입, JWT 기반 인증
- 화상 진료를 위한 시그널링 서버(Node.js, 별도 저장소)와 연동

## 기술 스택

- Java, Spring Boot, Spring Data JPA, Spring Security, JWT
- PostgreSQL
- AWS EC2

## 배포

AWS EC2 — 프로젝트 막바지(2025.12) 본인이 단독으로 배포 진행
